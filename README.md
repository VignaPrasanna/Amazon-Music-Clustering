**AMAZON MUSIC CLUSTERING**

the project is to categorize songs from the amazon music dataset using the unsupervised Machine Learning technique K-Means clustering. Here the dataset is clustered into k clusters where the best k value is determined using the elbow method, Silhouette score and Davies-Bouldin Index and then we add cluster labels to the dataset so that streaming platforms can use this data to help listeners and artists to discover songs suited to their liking or curate playlists and so much more.
